# Energiearmoede website (multi-page)

## Openen
- Pak de zip uit
- Open `energiearmoede_site/index.html` in je browser

## Vervangen van figuren
- `energiearmoede_site/assets/essent_heatmap_placeholder.svg` vervangen door jouw Essent heatmap (PNG/SVG)
- `energiearmoede_site/assets/trend_placeholder.svg` vervangen door jouw trendgrafiek (PNG/SVG)
- Optioneel: `energiearmoede_site/assets/prisma_placeholder.svg` vervangen of verwijderen

## Structuur
- index.html (managementsamenvatting)
- inleiding.html
- methode.html
- analyse.html
- ai.html
- conclusie.html
- bronnen.html

Tip: zet onder elke figuur bron + peildatum.
